# 🦷 عيادة ابتسامة

مشروع تطبيقي لدورة **«خلّ Claude يشتغل على منصتك»**.

هذا موقع بسيط لحجز المواعيد في عيادة أسنان. في الدورة نربطه بـ Claude عن طريق **MCP**، حتى يتمكن المريض من حجز موعده وإلغائه من محادثة Claude مباشرة.

| الفرع | المحتوى |
| --- | --- |
| `main` | كود البداية: موقع العيادة بدون MCP. ابدأ من هنا. |
| `solution` | الحل: الموقع نفسه + MCP Server على `/api/mcp`. |

## ماذا يقدّم الموقع؟

- صفحة الخدمات: كشف، تنظيف، حشوة، تبييض
- الأوقات المتاحة لكل خدمة
- حجز موعد وإلغاؤه
- صفحة «مواعيدي»، وكل مريض يرى مواعيده هو فقط
- تسجيل الدخول بالبريد الإلكتروني وكلمة المرور

**التقنيات:** Next.js (App Router) و TypeScript و Tailwind، وقاعدة Postgres على Neon، وتسجيل الدخول بـ Better Auth.

## التشغيل المحلي

تحتاج **Node.js 20** أو أحدث.

### ١) نزّل المشروع

اعمل Fork للمستودع، ثم:

```bash
git clone <رابط نسختك>
cd smile-clinic-mcp
npm install
```

### ٢) أنشئ قاعدة بيانات على Neon

1. سجّل في [neon.tech](https://neon.tech) وأنشئ مشروعًا جديدًا (الخطة المجانية تكفي).
2. من صفحة المشروع اضغط **Connect** وانسخ الـ Connection string.

### ٣) جهّز ملف `.env`

```bash
cp .env.example .env
```

املأ القيم:

| المتغير | القيمة |
| --- | --- |
| `DATABASE_URL` | الرابط الذي نسخته من Neon |
| `BETTER_AUTH_SECRET` | مفتاح عشوائي، ولّده بالأمر `openssl rand -base64 32` |
| `BETTER_AUTH_URL` | `http://localhost:3000` |

> ⚠️ ملف `.env` فيه مفاتيحك السرية، ولا يُرفع إلى GitHub (موجود في `.gitignore`).

### ٤) جهّز قاعدة البيانات

```bash
npm run db:setup
```

هذا الأمر يعمل خطوتين:

1. `db:migrate`: ينشئ جداول تسجيل الدخول الخاصة بـ Better Auth.
2. `db:seed`: ينشئ جداول العيادة، ويضيف الخدمات، وأوقاتًا لـ **٦٠ يومًا** قادمة، والحسابين التجريبيين.

يمكنك تشغيله أكثر من مرة بأمان، فهو لا يكرر شيئًا موجودًا.

### ٥) شغّل الموقع

```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) وسجّل الدخول بأحد الحسابين:

| البريد | كلمة المرور |
| --- | --- |
| `demo@smile.clinic` | `demo1234` |
| `sara@smile.clinic` | `demo1234` |

جرّب أن تحجز بحساب، ثم تدخل بالحساب الثاني: لن ترى مواعيد الحساب الأول.

### تجديد الأوقات

الـ seed يضيف أوقاتًا لـ ٦٠ يومًا فقط. إذا اقتربت الأوقات من النفاد، شغّل:

```bash
npm run db:slots
```

يضيف أوقات الـ ٦٠ يومًا القادمة من اليوم، **ولا يحذف ولا يعدّل** أي وقت أو موعد موجود.

### حل المشكلات

**تسجيل الدخول لا يعمل وتظهر رسالة `Invalid origin`**
يجب أن يكون المنفذ (port) في `BETTER_AUTH_URL` هو نفس منفذ الموقع. إذا كان المنفذ 3000 مستخدمًا، يشغّل Next.js الموقع على 3001 تلقائيًا (انظر الطرفية). في هذه الحالة غيّر `.env` إلى:

```
BETTER_AUTH_URL=http://localhost:3001
```

**تحذير طويل عن `sslmode` عند تشغيل الأوامر**
لا يؤثر على عمل المشروع. لإخفائه، غيّر نهاية `DATABASE_URL` من `sslmode=require` إلى `sslmode=verify-full`.

## النشر على Vercel

1. ارفع نسختك إلى GitHub، ثم من [vercel.com/new](https://vercel.com/new) استورد المستودع.
2. **قاعدة البيانات**، اختر طريقة واحدة:
   - استخدم قاعدة Neon التي أنشأتها، وأضف `DATABASE_URL` في متغيرات البيئة.
   - أو من تبويب **Storage** في مشروعك على Vercel أضف **Neon**. سيضيف Vercel المتغير `DATABASE_URL` تلقائيًا. انسخ قيمته إلى `.env` وشغّل `npm run db:setup` على جهازك مرة واحدة لتجهيز هذه القاعدة.
3. من **Settings → Environment Variables** أضف:
   - `BETTER_AUTH_SECRET`: مفتاح جديد، ولا تستخدم مفتاح جهازك نفسه.
   - `BETTER_AUTH_URL`: رابط موقعك على Vercel، مثل `https://smile-clinic.vercel.app`.
4. اعمل **Redeploy** حتى تُطبَّق المتغيرات.

## خريطة الكود

```
app/
  page.tsx                  صفحة الخدمات
  services/[id]/page.tsx    الأوقات المتاحة لخدمة واحدة + الحجز
  appointments/page.tsx     «مواعيدي» + الإلغاء
  sign-in/page.tsx          تسجيل الدخول
  actions.ts                Server Actions للحجز والإلغاء
  api/auth/[...all]/        مسارات Better Auth
lib/
  clinic.ts                 ⭐ منطق العيادة كله: الخدمات والأوقات والحجز والإلغاء
  auth.ts                   إعداد Better Auth
  session.ts                getUser و requireUser
  db.ts                     الاتصال بـ Postgres
  format.ts                 تنسيق التاريخ والوقت والأرقام بالعربي
db/
  schema.sql                جداول العيادة
  seed.ts                   البيانات التجريبية
  slots.ts                  توليد الأوقات
  refresh-slots.ts          سكربت npm run db:slots
```

**أهم ملف في الدورة هو `lib/clinic.ts`.** كل دالة فيه تأخذ رقم المستخدم (`userId`)، وتعمل على مواعيده هو فقط، وترجع `{ ok: true, data }` أو `{ ok: false, error }` برسالة واضحة مثل «هذا الوقت محجوز، جرّب وقتًا آخر.». في المرحلة الثانية تستدعي أدوات MCP هذه الدوال نفسها، فلا نعيد كتابة أي منطق.

**منع الحجز المزدوج:** في `db/schema.sql` يوجد `unique index` يمنع وجود موعدين محجوزين على نفس الوقت. حتى لو ضغط مريضان «احجز» في اللحظة نفسها، تقبل قاعدة البيانات حجزًا واحدًا فقط.
